Skema Data & Cara Kerja Sinkronisasi (data.json)

Dashboard membaca file data.json di folder yang sama dengan index.html, berisi array objek harian. Jika file belum ada / gagal dimuat, dashboard otomatis memakai data contoh di bawah ini (bukan data GSheet Anda) supaya tampilan tetap bisa dicek. Dashboard juga polling ulang data.json setiap 30 detik, jadi begitu Apps Script Anda menulis ulang file tersebut, angka akan mengikuti tanpa perlu refresh manual.

Field JSON per baris (nama field di kiri ↔ perkiraan kolom sheet "Data" di kanan — akan saya cocokkan persis setelah Anda kirim link sheet-nya):

Contoh satu baris data.json:

Production KPI Dashboard · dibuat sebagai file HTML mandiri · sumber data: Google Sheet → Apps Script → data.json
